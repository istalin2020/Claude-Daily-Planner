📤 How to Export for App Store Connect

  1. Open each screenshot_XX_name.html file in Safari on your Mac
  2. Go to File → Export as PDF — or use ⌘ + Shift + 4 to take a screenshot of the browser window
  3. For best quality: Set browser zoom to 200% before screenshotting (gives ~780×1688 px)
  4. Upload each image to App Store Connect → App Store → Screenshots
  5. App Store required sizes: 6.9" (1320×2868) · 6.7" (1290×2796) · 6.5" (1242×2688)
